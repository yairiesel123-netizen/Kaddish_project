# Project: Kadish Project (אתר קדיש לדורות)

## Role & Strict Rules (חוקי עבודה מחייבים)
1. Do NOT add any features, pages, or external packages unless explicitly requested.
2. Follow instructions literally and step-by-step. Do not make speculative assumptions.
3. Keep the code as simple, clean, and lightweight as possible (Vanilla HTML/CSS/JS).
4. All UI text must be in Hebrew (RTL support is mandatory).

## Target Audience & UX Constraints
- Target audience: Elderly users (65+).
- High accessibility: Large typography (minimum 18px body, high contrast).
- No small click targets; huge buttons and clear labels.
- Layout: Fixed right sidebar for navigation, wide main content area on the left.
